2 Crear el juego con IA (Claude)

Repetí este proceso las veces que haga falta: pedir, probar, corregir.

  1. Definan la mecánica en papel antes de escribirle a la IA: ¿decisiones con puntaje?, ¿plataforma con obstáculos?, ¿ambas cosas como el ejemplo?
  2. Arma el prompt con las 5 partes (Rol, Tarea, Formato, Estilo, Restricciones) usando tu tema de grupo en vez de "cuotas".
  3. Pedí el archivo como un único HTML autocontenido, sin dependencias externas salvo Google Fonts.
  4. Probalo abriendo el archivo en el navegador (doble clic) o pidiéndole a la IA que te lo muestre.
  5. Iterá con pedidos concretos: "cambiá el escenario 3 por...", "agregá una medalla si...", en vez de reescribir todo de nuevo.

Plantilla de prompt para tu grupo

Actuá como un desarrollador de videojuegos educativos especializado en HTML, CSS y JavaScript puro. Quiero que crees un juego educativo de un solo archivo HTML sobre "[TU TEMA DE GRUPO]" para adolescentes, con 5 decisiones/escenarios basados en la pregunta: "[TU PREGUNTA DISPARADORA]". Cada decisión debe sumar o restar puntos a un indicador principal, con las opciones en orden aleatorio. Entregame el resultado como un único archivo HTML autocontenido, sin dependencias externas salvo tipografías de Google Fonts. Usá una paleta de colores clara, diseño limpio, tono cercano para adolescentes. Restricciones: debe funcionar sin conexión (salvo fuentes), ser jugable desde celular, sin violencia ni lenguaje ofensivo, basado en situaciones reales de adolescentes en Argentina.
Tip Cuanto más específica la TAREA (cuántos niveles, qué mecánica, qué pasa al ganar/perder), menos tiene que inventar la IA por su cuenta.

3 Publicar el juego: GitHub + Vercel

Así cualquiera puede jugarlo desde un link, sin instalar nada.

A. Crear una cuenta en GitHub

  1. Entrá a github.com y hacé clic en Sign up.
  2. Cargá un usuario, tu email y una contraseña. Confirmá tu cuenta desde el mail que te llega.
  3. Con la cuenta creada, hacé clic en el botón verde New (o el símbolo + arriba a la derecha → New repository).
  4. Ponele un nombre al repositorio (por ejemplo, el nombre de tu juego sin espacios), marcalo como Public y hacé clic en Create repository.
  5. Dentro del repositorio, hacé clic en Add file → Upload files y arrastrá el archivo .html que armaron con la IA. Asegurate de que se llame index.html.
  6. Confirmá la subida con Commit changes.

B. Conectar con Vercel y publicar

  1. Entrá a vercel.com y hacé clic en Sign Up.
  2. Elegí Continue with GitHub para vincular directamente la cuenta que acaban de crear.
  3. Autorizá el acceso de Vercel a GitHub cuando te lo pida.
  4. En el panel de Vercel, hacé clic en Add New… → Project.
  5. Buscá y seleccioná el repositorio que crearon (el de su juego) y hacé clic en Import.
  6. Dejá la configuración por defecto y hacé clic en Deploy.
  7. Esperá unos segundos: Vercel les va a dar un link tipo tu-juego.vercel.app. Ese es el link para compartir y jugar desde cualquier dispositivo.
Si después cambian el juego Subiendo el archivo actualizado al mismo repositorio de GitHub (Upload files → Commit changes), Vercel actualiza el sitio publicado automáticamente, sin tener que repetir todo el proceso.
